# Virtual Assistant

A desktop voice and text assistant with a futuristic Tkinter interface, animated cyan avatar, system utilities, and web integrations.

## Setup

From this directory, install the dependencies:

```powershell
python -m pip install -r requirement.txt
```

Start the application:

```powershell
python gui.py
```

Generate the school project report PDF:

```powershell
python generate_project_report.py
```

This creates `Himank_Gupta_AI_Assistant_Project.pdf` with 24 numbered pages.

The interface opens with a centered avatar window. Use **ASK VOICE** for microphone input or type a command and press **SEND**.

## Commands

- `Open Task Manager`
- `Show System Specs`
- `Roll a Die`
- `What's the date?`
- `What is the time?`
- `Find SQL tutorial videos`
- `Play Human Knowledge by Sophia Isla`
- `Open Google` or `Open YouTube`
- `Weather`
- `Go offline, Jarvis`

The voice feature requires a working microphone and internet access for Google speech recognition. The weather and YouTube features also require internet access.
